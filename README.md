# Website - Lumix

Este directorio contiene **exclusivamente el código fuente y assets de producción** destinados a desplegarse en Cloudflare Pages y GitHub.

- **Repositorio Remoto:** `https://github.com/ItsJolex3630/lumix-website`
- **Cloudflare Pages:** `lumix-website`
- **Framework/Stack:** Vanilla HTML5 / TailwindCSS / Alpine.js o React/Vite.

### Reglas para Agentes de Código:
1. Este directorio es el único que contiene `.git`.
2. Las variables de entorno privadas deben declararse en el panel de Cloudflare o en un archivo `.env` local (nunca comitear).
